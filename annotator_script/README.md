# ExpoPortal Annotator script
This script has been generated to annotate interview dataset [Seeing what they see: Compensating for cortical visual dysfunction in Alzheimer's disease 2014-2018](https://reshare.ukdataservice.ac.uk/853147/) using ExpoPortal annotator API. Annotator strips questions by interviewer and filters out common conversation words. Output consists of two files, one for demographic information of the interviewed subject and the other for ontology annotated terms and their occurrence.


It can be run as `python3 annotate_file.py input.txt [-o out.csv] [-d demographics.csv] [--ontologies A,B] --apikey YOUR-KEY`.


The script was generated using Claude Opus 5.5 for the purposes of Project 19 at BioHackathon Europe 2026. It seems to be a dead end and probably won't be worked on further. We are providing it for archival purposes only.
